# v7 parity report

Final measurement of the v7 prototype and the TypeScript port, taken before the bot weights are changed.

- Setup: 100 seeds. Bots play 400 games per seed per profile per mode. Generator buckets sample 100,000 cards per seed.
- Both sides are averages over the 100 seeds. `z = (port - v7) / sqrt((sd_v7^2 + sd_port^2) / 100)`, so z counts standard errors of the difference. About |z| < 3 is noise.
- v7 numbers are stored in `tools/baseline/v7-final.json` (mean and sd per metric). They came from a harness that ran the prototype headless in a `node:vm` context with a seeded `Math.random`. The harness (`tools/baseline/capture.mjs`, `harness.mjs`, `policies.mjs`) was removed after this report; get it from git history.
- Port numbers came from a throwaway slow test that ran the port over the same seeds and counts. It was removed after this report; see git history.

## Verdict

- Generator: all buckets match. No metric is beyond |z| 4.5 in any of the 8 buckets.
- Bots: 26 of 132 bot metrics are beyond |z| 4.5. They are small and one-sided: the port is slightly stronger than v7 (hearts +2.4% Mixed long, +2.8% Smart long, +3.5% Build standard, +3.7% Build long). Build differs the most. None (a no-recruit bot) shows +13% on a tiny base (2.25 to 2.55 hearts).
- Cause not yet known. Candidates: policy details that differ from v7, and weighted sampling in the port against v7's fixed choice order.
